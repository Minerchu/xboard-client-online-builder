连接配置

软件名称将公开显示在编译记录中，请勿包含个人信息、辱骂或违规内容。

在线 JSON 地址填写完整文件网址，如 https://example.com/client.json；末尾按实际文件地址填写，不能只填域名。备用 Xboard API 只填站点域名，如 https://panel.example.com；末尾有无 / 均可，不要加 /api/v1、订阅路径或 token。

在线 JSON 文件的标准格式（换行只是为了易读，单行也可以；使用英文双引号）：

{
  "api": "https://panel.example.com"
}

客户端优先读取在线 JSON；读取失败才使用备用 Xboard API。以后修改在线 JSON 的 api 值，无需重新打包。
