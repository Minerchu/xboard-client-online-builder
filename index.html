Windows 打包

基于潮汐客户端改造，适配 Xboard；使用 Mihomo 内核，支持 VLESS、Hysteria2、AnyTLS 等协议。

客户端每次启动时读取此地址；以后修改 JSON 内容，无需重新打包。请使用 HTTPS 完整链接。

{
  "api": "https://your-xboard.example.com"
}

花括号换行只是排版，不换行也有效；键名必须是 api，值填写 Xboard 网站根地址，不要加 /api/v1。

在线 JSON 读取失败时使用。末尾的 / 可写可不写，不要填写 /api/v1 或订阅链接。
